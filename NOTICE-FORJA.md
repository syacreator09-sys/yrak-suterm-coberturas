# Aviso de atribución de Forja

Este proyecto adopta de forma selectiva patrones y componentes del proyecto open source **Forja**, creado por Horizontes IA y publicado bajo licencia MIT.

Repositorio de origen: `santmun/forja`.

La adopción se limita al chasis técnico de Cloudflare, adaptadores de canales, proveedores de modelos y patrones de agente. Las reglas laborales, motores de rotación, elegibilidad, concurso, auditoría y asignación fueron diseñados específicamente para YRAK Coberturas.

La licencia original de Forja se conserva en `third-party/forja/LICENSE` cuando se incorpore código literal o sustancialmente derivado.
