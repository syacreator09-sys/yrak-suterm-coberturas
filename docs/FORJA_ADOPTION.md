# Adopción controlada de Forja

Referencia: `santmun/forja`, licencia MIT.

Patrones permitidos para adoptar o reimplementar:

- Hono sobre Cloudflare Workers.
- Proveedores de IA intercambiables.
- Durable Object como coordinador con estado.
- R2 para media/evidencias.
- Recepción de mensajes y notas de voz.
- Panel administrativo como superficie web.

No se importan leads, ventas, CRM ni reglas comerciales de Forja. El dominio YRAK es independiente y determinista.
