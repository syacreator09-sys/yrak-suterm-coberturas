# Operación de inconformidades

## Antes de adjudicación

Una inconformidad `OPEN` o `UNDER_REVIEW` asociada al expediente bloquea la adjudicación del concurso. El responsable debe resolverla o rechazarla con fundamento antes de adjudicar.

## Después de adjudicación

El sistema permite conservar una inconformidad como expediente histórico, pero **no revoca automáticamente** una asignación ya adjudicada porque todavía no existe una regla oficial que defina:

- autoridad para revocar;
- efecto suspensivo o no;
- sustitución por segundo lugar;
- repetición del examen;
- plazo de resolución;
- efecto sobre una cobertura ya iniciada.

Una revocación automática sin esa norma sería una decisión laboral inventada.

## Principio de implementación

Cuando se reciba la política formal, el flujo de apelación debe convertirse en estados/reglas deterministas y conservar:

1. resultado original;
2. motivo de inconformidad;
3. evidencia;
4. decisión/resolución;
5. actor(es) autorizados;
6. efecto sobre ranking/asignación;
7. todas las notificaciones;
8. auditoría before/after.
