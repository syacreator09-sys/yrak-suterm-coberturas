# Contribuir

1. Crear una rama desde `main`.
2. Agregar o actualizar pruebas.
3. Ejecutar `pnpm lint`, `pnpm typecheck`, `pnpm test` y `pnpm build`.
4. Documentar migraciones y cambios de reglas.
5. Abrir un pull request con impacto, riesgos y evidencia de pruebas.

No se aceptan cambios que permitan a un LLM decidir asignaciones o alterar la auditoría.
