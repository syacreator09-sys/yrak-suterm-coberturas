# Seguridad

Este repositorio es privado y puede procesar datos laborales sensibles.

## Reporte

Reportar vulnerabilidades de forma privada al propietario del repositorio. No abrir issues públicos con datos, tokens o evidencia sensible.

## Reglas

- Secretos únicamente mediante `wrangler secret put` o secretos de GitHub.
- Archivos originales en R2 privado con URLs firmadas y expiración.
- Auditoría append-only.
- Principio de mínimo privilegio.
- Validación MIME, tamaño, hash y contenido para adjuntos.
- No registrar tokens, respuestas completas de proveedores o PII innecesaria.
